# Lovable Handoff

Use this file to collect everything needed for Codex to manage Lovable prompts and project direction.

## Needed From Lovable

- Project URL or project ID.
- Current page list.
- Screenshots of the marketing site.
- Screenshots of the dashboard.
- Database/schema view.
- Auth/provider setup.
- Any connected APIs.
- Current prompt history, if available.

## Questions To Answer

- Which screens are complete?
- Which screens are placeholders?
- Is the dashboard connected to real data?
- Where are leads stored right now?
- Does the app already have user roles?
- Is there a client/business settings page?
- Can the project export to GitHub?
