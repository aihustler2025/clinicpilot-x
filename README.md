# ClinicPilot X

ClinicPilot X is a Buzzooka-owned product for automating lead intake, email triage, client notifications, and follow-up workflows for clinics, med spas, dentists, salons, and related service businesses.

## Folder Map

- `00-admin` - business setup, credentials notes, vendors, access checklists, legal/compliance notes.
- `01-strategy` - business model, positioning, ICP, pricing, roadmap, decisions.
- `02-product` - feature specs, user flows, MVP scope, QA notes, product backlog.
- `03-lovable` - Lovable prompts, screenshots, exports, build notes, handoff summaries.
- `04-automations` - n8n, Make, Cloudflare, email/SMS workflow designs, JSON exports.
- `05-backend-data` - database schema notes, Convex/backend plans, API contracts, sample data.
- `06-sales-marketing` - landing page copy, offers, outreach scripts, demos, case studies.

- `08-research` - competitor research, vendor comparisons, pricing notes, compliance research.
- `09-exports` - code exports, zipped backups, generated reports, snapshots.
- `99-archive` - old material kept for reference.
