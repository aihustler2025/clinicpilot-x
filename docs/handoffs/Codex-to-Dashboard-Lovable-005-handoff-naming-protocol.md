# Codex To Dashboard Lovable 005: Handoff Naming Protocol

```text
Please follow this handoff naming convention for future responses so the owner can save and track our back-and-forth quickly.

When you reply to a Codex handoff message, include this line near the top of your answer:

Suggested response filename: Dashboard-Lovable-to-Codex-###-[short-topic].md

Use the same number as the Codex message when possible.

Examples:

- If Codex sends `Codex-to-Dashboard-Lovable-004-admin-access-recovery.md`, reply with suggested filename:
  `Dashboard-Lovable-to-Codex-004-admin-access-response.md`

- If Codex sends `Codex-to-Dashboard-Lovable-005-handoff-naming-protocol.md`, reply with suggested filename:
  `Dashboard-Lovable-to-Codex-005-handoff-naming-protocol-response.md`

Please also keep your response structured with:

1. Summary
2. What was done or found
3. Files changed, if any
4. Database or integration changes, if any
5. Testing/verification results
6. Remaining risks or blockers
7. Suggested next step

This is a workflow instruction only. Do not change product code for this message.
```
