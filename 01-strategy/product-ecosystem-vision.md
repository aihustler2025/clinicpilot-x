# ClinicPilot X Product Ecosystem Vision

Updated: 2026-05-22

## Positioning

ClinicPilot X is a standalone Buzzooka-owned product, but it can grow into a broader product ecosystem for clinics, med spas, dental practices, salons, beauty/wellness businesses, and other appointment-based service businesses.

## Core Product

### ClinicPilot X Dashboard

The main operating system for clinic lead intake, CRM, appointments, staff workflow, automations, and reporting.

Immediate focus:

- Secure the Dashboard Lovable project.
- Add auth/roles.
- Connect real lead intake.
- Port marketing pages later.

## Extensions / Future Products

### Chatbot Plugin

Separate Lovable project already exists, partially built.

Vision:

- Embeddable chatbot/plugin for client websites.
- Should work on WordPress and non-WordPress sites.
- Answers visitor questions, provides customer support, captures leads, and routes conversations into ClinicPilot X.
- Can be sold as an add-on or included in higher ClinicPilot X tiers.

Status:

- Existing Lovable project mentioned by owner.
- Not yet audited by Codex.
- Do not work on this until Dashboard Lovable Step 1 security/auth is complete.

### Clinic Website Package

Website product/offer that can be bundled with ClinicPilot X.

Vision:

- A ready-to-use website for clinics/businesses that is already tested with ClinicPilot X and the chatbot plugin.
- Can be positioned as a sales incentive: subscribe to ClinicPilot X and get a website that is built to integrate with the platform.
- May help close clients who want both automation and a modern web presence.

Status:

- Related website project exists or is being built for a client.
- Not yet audited by Codex.
- Keep separate until ClinicPilot X MVP is stable.

### Staff/In-House App

Future app for clinic staff/internal use.

Vision:

- Staff can manage leads, patients, appointments, tasks, reminders, and internal workflow from an app.
- Could be mobile-first or companion app to the dashboard.

Status:

- Future roadmap only.

## Possible Packaging

Potential pricing/product structure later:

- Tier 1: Core dashboard and lead intake.
- Tier 2: Dashboard plus chatbot plugin.
- Tier 3: Dashboard plus chatbot plus website package and advanced automation.

Exact packaging is not decided.

## Guardrail

This ecosystem vision should not delay the one-week ClinicPilot X MVP. Current priority remains:

1. Dashboard Lovable security/auth.
2. Real lead intake.
3. Dashboard visibility.
4. Owner/staff notification.
5. Draft reply/manual review workflow.
